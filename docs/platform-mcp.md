# 内置平台 MCP

finfreedom 在 Agent 运行时自动注册 `finch` stdio MCP。连接显示在「数据与模型 → MCP 连接」中，不能由普通 MCP 配置覆盖或移除。Web 服务把已认证的账户 ID 注入独立 MCP 进程；模型参数不能指定或更换账户。

## 工具

| 工具 | 用途 |
| --- | --- |
| `mcp__finch__catalog` | 查询可读资源、可写资源和操作类型 |
| `mcp__finch__read` | 按资源名读取与页面同源的数据，可传筛选和分页参数 |
| `mcp__finch__write` | 修改当前用户管理的工作台内容 |

`read` 覆盖持仓、自选、行情、市场状态、交易日历、指数、数据源状态、新闻、流动性、板块、资金、标的、日线、研报资料、投研记录、回测、投资记忆、AI 词条和右栏卡片。详细资源名由 `catalog` 返回；大列表需要指定 `limit`，研报正文按 `document_id` 和 `page` 读取，单条投研记录按 `run_id` 读取。

模拟炒股与实盘交易页面也由同一个 `read` 工具覆盖。交易资源全部只读，账户身份由可信运行时固定；富途 OpenD 只绑定本机主账户。`limit` 最多 100，列表可用 `offset` 分页。

| 资源 | 内容和参数 |
| --- | --- |
| `paper_local_accounts` | 本地模拟账户的现金、持仓、估值；可传 `account_id` 获取单账户 |
| `paper_local_orders` | 本地模拟委托；可传 `account_id`、`limit`、`offset` |
| `paper_local_ai_runs` | AI 模拟交易任务；可传 `run_id` 查看任务证据及订单，或按 `account_id` 分页 |
| `paper_futu_accounts` / `live_futu_accounts` | 富途 SIMULATE / REAL 账户目录；先读取目录，再传 `connection_id` 读取 OpenD 资金与持仓快照 |
| `paper_futu_orders` / `live_futu_orders` | 本平台记录的富途 SIMULATE / REAL 委托回报；可按 `connection_id` 分页，不能代表券商全部历史委托 |

AI 分析时需区分本地模拟、富途模拟及富途真实账户，引用返回的来源、数据时点和估值完整性。富途账户目录不暴露完整券商账户号；MCP 委托结果不暴露请求幂等标识、订单预览令牌或 OpenD 交易凭据。无富途账户或 OpenD 未连接时返回明确状态，不把空数据解读为零资产。

`write` 支持：

- 右栏卡片顺序、显隐、宽度与展开状态；创建、编辑、删除自定义 Markdown 笔记卡片；修改内置卡片的显示标题和附注。
- 日历计划、事件、订阅与闹钟确认。
- 自选添加与移除、真实持仓快照登记、当前 llm-wiki 文档编辑。
- AI 词条的创建、编辑、收藏、删除；新闻推荐词条只在编辑后保存为当前用户的词条。

右栏内置卡片的市场数值始终来自真实页面数据源。标题和附注不会改写行情或研究证据。持仓快照采用原有的 `expected_updated_at` 乐观锁；wiki 编辑采用 `expected_sha256`；卡片和日历采用 `expected_version`。Agent 必须先读后写，再读确认结果。MCP 不提供凭据、原始历史会话、任意 SQL、任意文件操作或实盘下单。

页面和 MCP 共用 `owner_workspace_state`。原浏览器日历记录及右栏偏好会在首次载入时迁入当前账户；其后的更改以服务端版本为准。页面每次进入日历时刷新日历数据，工作台定时刷新卡片与提醒状态。

现有自选、导入资料和回测记录仍沿用项目原有共享数据表；MCP 对这些资源采用与现有页面相同的可见范围。持仓、工作台状态、投研记录和投资记忆则按账户隔离。多账户部署前需要把旧共享表迁移到按账户存储。
