# 本地账户安全

## 当前认证策略（009，2026-10-26）

按用户明确要求，默认账号密码登录，取消强制验证器；短信为可选登录保护。升级撤销旧会话，保留既有用户名、Argon2id密码、资料和模拟盘。刷新网页后使用原密码即可。

首次账户仍由本人在项目终端运行 `docker compose exec web python -m app.manage init-owner` 设置，无默认密码或公开注册。忘记密码使用同一容器内的 `reset-password`，不通过聊天收集密码。

会话为服务端可撤销的HttpOnly / SameSite=Strict Cookie，最长8小时、默认闲置20分钟锁定。Origin、Host、CSRF、CSP、非回环HTTPS约束及HMAC审计链保留。密码变更和认证策略变更撤销所有旧会话。交易、开户、清零等敏感操作要求最近5分钟密码确认并轮换会话/CSRF；原有预览、危险确认及服务器风控继续有效。

短信模式要求先验证密码，再消费一次性验证码；挑战不是完整会话。固定接收本人号码、60秒间隔、3次/挑战、10次/滚动24小时、5次错误、5分钟有效。验证码只存HMAC摘要，首次登录阶段绑定浏览器Cookie、本人、密码版本及短信配置，成功原子消费。原文短信码和供应商凭据不进入日志、URL或审计。未知发送不自动重发。

`AUTH_AUDIT_KEY`继续用于审计签名及SMS摘要，`AUTH_ENCRYPTION_KEY`保留本机安全配置和旧数据兼容；旧TOTP种子不再参与认证，旧设置/扫码端点撤下。请保管 ENV、Compose secret 和 MySQL 数据卷备份；有 Docker 管理权限的操作者可访问数据库。MySQL 默认不发布宿主端口，持久卷仍需磁盘与备份加密。

配置与官方来源见 [SMS_SETUP.md](SMS_SETUP.md)。当前只接火山短信，不做邮件、短信免密登录或公开注册。没有实际短信凭据时不能声称真实送达已验证。

## 模拟与真实资金边界

模拟账户按owner_id校验，订单、成交、AI任务按账户隔离；服务器固化白名单、额度、笔数，清零需危险确认/近期密码/CSRF/幂等。模型不能改变账户归属或扩大权限。实盘仍暂缓，券商草案未加载运行时，不需要券商账号密码。

用户密码、手机完整号码、模型密钥、短信AK/SK只在本人终端/本地ENV及受保护服务端处理。短信服务会收到已配置本人号码和验证码；含账户数据的AI分析仍需原有明确授权。
