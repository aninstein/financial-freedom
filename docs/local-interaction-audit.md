# 页面局部交互检查（2026-10-26）

## 原因

`app.js` 的 `renderRoute()` 原先对每次 `hashchange` 都清空 `#page`、展示整页加载态、重置滚动并把焦点移到页面容器。K 线周期与根数使用 URL 参数，因此也进入这条路径，并重复请求指数或个股数据。大盘默认路径 `#/indices` 的图表链接还会跳到 `#/indices/<id>`，导致第一次切换必然被视为页面导航。

## 已检查的局部控制

| 页面 | 局部控制 | 现在的更新范围 |
| --- | --- | --- |
| 大盘与指数 | 指数选择；日、周、月 K；60/120/250 根；历史滑块 | 周期、根数、滑块只重绘 K 线区域；指数选择更新同页数据节点 |
| 个股详情 | 标签、资料类别；K 线周期、根数、历史滑块 | 标签/资料更新同页节点；K 线控制只更新图表区域 |
| 市场总览、自选 | 市场筛选、关键词、分页 | 保留页面框架，更新变化节点 |
| 新闻与流动性、板块轮动与资金、资金与基金 | 关键词、轮动阶段、分页 | 保留页面框架；轮动阶段和分页只更新轮动区域 |
| 交易日历 | 日期、月/周视图、折叠、账户 | 保留页面框架，更新变化节点 |
| 模拟交易 | 账户、订单类型、分页 | 保留页面框架，更新变化节点 |
| 研报资料等其他同路由刷新 | 筛选或手动重新请求 | 保留页面框架，更新变化节点 |

跨页面导航仍走完整路由；同路由更新期间旧数据可见，失败时保留旧内容并显示通知。URL 参数继续支持书签和浏览器前进后退。局部 DOM 更新保留未变化的节点、滚动位置与焦点。
