# 003 · Agent 投研工作空间

## 目标

以 VOS/Duet 的会话结构替换全功能滚动单页。用户先与 Agent 交流，按需要进入股票、板块及研究数据页，持续保留当前对话。

## 用户故事与验收

1. 首页对话、左侧菜单、右侧个人上下文；窄屏用模态菜单/上下文窗口。导航切换独立内容，不滚动锚点。
2. 搜索名称/代码定位标的，自选支持增删及行情/均线/波动展示；个股详情可采集日线、查看真实曲线、关联资料和研究历史。
3. 问个股/板块时调用实际数据工具，回答附确定性证据卡片，点击打开详情；从详情可把代码/行业名带回对话草稿。
4. 对话携带最近消息理解指代，当前市场数据重新查询；错误保留问题、提供配置/重试入口。模型未配置不生成假回答。
5. 板块目录、成分股、行业资金分别查询，返回部分/完整/过期/不可用状态。主力成交分类统计不能冒充北向资金或基金实际操作。
6. 账户上下文默认关闭；模拟订单继续服务端预览、人工确认及幂等提交。Agent 无下单工具。

## 实现

轻量 ES modules + CSS；共享 ui.js/API client；FastAPI 增加 workspace 详情和行业端点；SQLite 缓存行业原始快照。原有 ENV 模型配置保持兼容。原有旧锚点映射至对应路由。

## 验证边界

模型未配置时只确认配置失败路径与交互结构，不能声明真实模型问答完成。行情和行业接口受 AKShare 上游可用性影响。当前没有 token streaming、完整多轮会话树存储、自动交易或自定义策略代码执行。
