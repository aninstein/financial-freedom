# Feature 002: AI 投研与市场研究 Agent

**状态：** 首个只读 MVP 已实现；数据源覆盖与评测能力仍为部分实现  
**日期：** 2026-10-25  
**目标：** 在现有本地量化工作台之上提供有来源、有时间点、可复查的 AI 投研研究能力。  
**相关：** [项目章程](../../.kittify/charter/charter.md)、[Feature 001 量化底座](../001-quant-trading-foundation/spec.md)

## 产品目标

用户可以用自然语言询问个股、大盘、研报、财报、量化策略、基金持仓及资金流数据。Agent 负责理解问题、选择只读数据工具、组织可验证证据，并生成结构化研究报告。数据库查询和数值计算交给确定性服务；语言模型负责归纳、解释、比较和表达不确定性。

Agent 是研究助手，不是自动交易员。此 Feature 不增加任何下单、撤单、账户变更或自动调仓能力；研究输出不得直接触发模拟盘或真实交易。

## 产品范围与决策

- **首发市场沿用 Feature 001：** A 股/创业板、港股、美股、基金/ETF、上海黄金交易所支持的黄金品种。每份分析声明实际覆盖的市场、标的和数据源。
- **语言：** 首版支持中文提问和中文报告；证券名称、代码、原始文件标题保留来源原文。
- **数据权限：** 复用本地行情、日线、交易日历、账户快照和回测；研报/财报/新闻/基金披露及资金流走单独的数据源适配器。数据源不可用时明确报告缺失，不用模型记忆填空。
- **范围控制：** “全市场/大范围”研究必须显式选择市场、筛选条件、数据区间、并发和结果上限，使用后台任务与进度/取消；禁止未限界的全站抓取或对来源造成高频请求。
- **账户隐私：** Agent 默认不读账户。用户显式开启“结合账户分析”时，只能读取当前选择的只读/手工快照或模拟账户视图；最小化传入模型的数据并记录访问范围。
- **AI 提供方：** 支持通过服务端配置选择云模型或本地兼容模型；API 密钥只在服务端环境变量/密钥管理中保存。未配置模型时，检索和确定性研究接口仍可用，AI 分析显示未配置。
- **ENV 配置：** 参考 `dual_ai_voice_demo`，通过 `MODEL_CONFIG_JSON` 配置 provider/model/base_url/api_key_env，通过 `PRIMARY_MODEL` 选择首选模型；`MODEL_TEMPERATURE`、`MODEL_TIMEOUT_SECONDS`、`AGENT_RUN_TIMEOUT_SECONDS`、`AGENT_MAX_TOOL_CALLS` 控制资源上限。
- **用户确认：** 研究任务可直接提交；AI 生成的候选策略、股票观点和市场观点均是研究结果，必须由用户自行决定下一步。没有 AI 到交易接口的调用路径。

## 用户故事与验收标准

### P1 — 询问个股和大盘趋势

用户可以问“分析某只股票”或“判断某市场未来一周的风险/趋势”。报告展示观察周期、计算截止时间、行情时效、价格和指标来源、趋势/情景分析、看多与看空依据、主要风险、缺失数据及不确定性。

**验收：**
- 结论引用到具体行情/指标或文档证据，并展示来源、采集时间、事件/披露时间。
- 指标由行情/因子服务计算；模型不能凭空给出价格、涨跌幅、成交额或技术指标。
- 对“未来”只写基于历史与当前证据的情景/风险，不将概率表述成保证或确定预测；周期和基准时间必填。
- 交易日历、行情时效或样本不足时，报告降低结论等级或拒绝给出趋势判断。

### P1 — 分析研报和财报

用户可以上传或选择已入库的研报、公告、年报、季报、业绩说明和电话会材料，询问摘要、业务变化、风险、管理层表述及不同报告期对比。

**验收：**
- 原文保留文档 ID、来源链接/文件名、发布日期、报告期、页码/章节及入库时间；引用能跳回原文位置。
- 表格、单位、币种、口径、期末日期与披露日期分开保存。OCR/表格解析低置信度时标记待核实。
- 财务数字优先读取已校验的结构化数据；生成摘要不得把同比、环比、报告期和发布日期混为一谈。
- 文档中的指令性文本按不可信内容处理，不能改变 Agent 权限或系统规则。

### P1 — 量化策略研究

用户可以让 Agent 提出可检验的策略假设，挑选现有数据/指标并运行可复现的历史实验。

**验收：**
- 模型只提交 schema 化的研究配置；确定性回测服务校验参数并执行，不允许模型自行编造绩效。
- 每次运行绑定策略版本、参数、标的池、数据集哈希、交易日历、复权规则、训练/验证/测试区间、基准、费用和滑点。
- 默认使用时间顺序的样本外验证；避免未来函数、幸存者偏差和报告期/公告披露时间泄漏。
- 报告收益、基准超额、最大回撤、波动率、交易次数、换手和成本，并标注样本、缺失、数据质量及过拟合风险。
- Agent 不得将策略结果转换为订单或自动执行。

### P1 — 基金筛选、持仓与资金流研究

用户可以批量筛选基金/ETF，分析公布的基金持仓、净值、份额变动、ETF 申赎/成交特征，以及北向/南向 Stock Connect 可用的流量和持股统计。

**验收：**
- “基金持仓”按披露期展示，不冒充实时组合；ETF 二级市场成交、基金 NAV、盘中估值、份额申赎分别建模。
- 每个批量任务明确 universe、筛选条件、时间范围、并发/速率、输出上限和数据源覆盖；返回完成/部分完成/失败及逐源错误。
- 不把基金规模、份额变化、ETF 成交额或持股变动自动称作“净资金流入”；只有源数据定义与计算口径成立时才输出资金流指标。
- 北向/南向资金字段注明口径、频率和披露制度。不能把实时买卖成交额/累计净买入等已停止发布的字段作为当前可取数据；缺失时说明官方数据披露范围与可替代的历史/持股统计。
- 不同市场/币种的金额不隐式相加；任何合并数字都显示换算来源和时点。

### P1 — 多源检索与证据回答

Agent 可从本地行情与回测、财报/公告/研报、基金披露、官方市场统计和已配置新闻源检索证据。

**验收：**
- 结构化事实优先走 SQL/API/确定性计算；文档类内容使用全文检索及向量召回，证券代码、市场、文档类型、时间窗可过滤。
- 每项事实保留 provider/source、原始 ID 或 URL、事件时间、抓取时间、单位、市场和授权/许可说明。
- 无证据的具体事实标记“未找到来源”；多个来源冲突时并列呈现时间和口径，不由模型静默挑选。
- 数据源有更新/修订时可创建新版本，原研究运行仍能指向当时的证据集。

### P2 — 研究观点候选与关注列表

用户可要求系统按明确条件筛出候选证券或主题，给出值得继续研究的理由和反证。

**验收：** 候选排序指标可解释；结果注明完整 universe、过滤条件和未覆盖证券；不得暗示确定的买卖建议或自动放入订单。

## 不在本 Feature 范围内

- AI 自动下单、撤单、实盘交易、模拟交易或自动调仓。
- 无明确许可时爬取付费研报、券商终端、需要登录的页面或高频采集任意网站。
- 将模型输出包装为确定的价格预测、收益保证或个性化投资承诺。
- 首期训练专属金融基础模型、构建自动因子发现集群或持续在线强化学习。
- 全市场实时组合级资金流；仅接入定义清晰且获得许可的数据。

## 非功能与治理要求

- 每次运行有 run ID、用户问题、模型/提示版本、工具清单、查询参数、来源集合、时间戳、耗时、错误和最终输出记录；密钥、个人信息和完整账户明细不得写入普通日志。
- 工具按最小权限注册为只读；模型无任意 SQL、shell、通用 HTTP 抓取或交易工具权限。
- 检索文档及新闻为不可信输入，提示注入不得越权。
- 长任务异步执行，支持状态、取消、重试预算及每源限流；失败源隔离，不阻塞市场基础 UI。
- 所有报告能复制/导出，并可打开引用材料；允许用户标记事实错误和无效引用。
- 保留数据源授权、再分发限制、隐私/留存期限和用户导入文档删除策略。

## 成功指标（首轮试运行）

- 报告中每条关键数值/事实均能定位到结构化来源或原文片段；引用可用率和错误引用率可测量。
- 相同数据快照和配置可重复回放工具调用、指标和回测；LLM 文本差异单独标记。
- 批量扫描能按任务上限、数据源限额完成或明确返回部分结果，且每个结果都保留 PIT 时间。
- 没有任何 Agent 工作流能创建或修改交易订单。

## 待产品评审的决策

1. LLM 部署：云模型优先，还是本地模型优先？是否必须支持离线？
2. 文档来源：首期只接受用户上传 + 官方免费披露，还是接入有授权的新闻/研报供应商？
3. 批量扫描默认范围：全市场日终扫描，还是仅用户指定市场/基金列表？
4. 个股/大盘报告默认观察周期和输出模板是什么？
5. 是否允许“结合账户快照”生成组合风险报告；默认关闭是否合适？
6. 北向资金专题接受官方历史日频/季度持股口径，还是需要采购可授权的专业数据？

## 对 Feature 001 的增量

- 复用 quote/bar/calendar/watchlist/accounts/backtests API 和历史数据表。
- 新增文档库、原文/页码定位、检索索引、研究运行记录、AI provider 设置、数据源目录和只读工具注册。
- Feature 001 的研究结果仅允许通过运行 ID 引用，不能把模型生成内容写入原始行情、账户、订单或成交表。

## 已知实现差距

- 当前文档检索是本地关键词匹配，不含向量召回或 OCR。
- 研究接口是有界同步请求，不含后台队列、取消或逐源配额面板。
- 当前未配置新闻/研报供应商；宽范围筛选只覆盖本地缓存行情。
- 北向/南向历史流量没有落入本地数据集；实时北向买卖成交额不可用。
