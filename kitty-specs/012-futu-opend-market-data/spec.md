# 012 富途 OpenD 行情接入

## 目标

在中国内地网络下，使用富途官方 OpenD 读取本人可用的 A、港、美市场行情，为大盘、关注标的、模拟盘和历史研究提供同一套带来源时间的数据。富途账号只在官方 OpenD 中登录，项目不保存富途密码，也不创建交易上下文。

## 范围

- OpenD 本机端口、安装和登录状态由「数据与模型」显示；未登录或权限不足时明确展示数据缺口。
- A 股六个指数与恒生指数优先从富途接收；美股指数 API 权限文档暂不支持的指数沿用公共源。
- 自选、模拟持仓和挂单中的 A、港、美股票及交易所 ETF 用富途订阅推送与定时快照；批次上限和速率低于官方接口限制。全部报价保留交易所时间、接收时间、来源和是否订阅推送。
- 历史日 K 优先请求富途，无权限、额度不足或失联时回退已有公开数据源，并按实际来源记录数据集。
- 模拟撮合仅使用带可核验来源时间且符合新鲜度要求的报价；富途凭证与交易密码不进入项目。

## 非范围

- 不使用富途实盘交易 API，不读取富途资金账户。
- 不把全市场证券发现、研报、财报、新闻、行业资金流、基金定期披露或黄金标记成富途数据；这些维持各自来源。
- 页面每秒刷新不意味着上游每秒成交或每秒有新报价。

## 验收

1. 未安装、未登录 OpenD 时，服务正常运行，公开行情回退仍可用，设置页显示等待登录。
2. OpenD 登录且有行情权限时，设置页显示实际收到的条数与时间；A 股、港股指数、自选和模拟盘价格展示真实富途来源与来源时间。
3. 实时订阅成功时，变化通过回调进入服务端；订阅失败但快照可读时使用快照，并保留延迟未知或来源实际时间。
4. 模拟单不会因刚刚接收了十五分钟延迟快照而误判为实时可成交。
5. 私人 `.env` 与 OpenD 登录信息不进入 Git、API 响应或前端代码。真实送达须在本人登录后按市场分别核验。
